Table header samples

Each table below has the same data: regions down the left and quarters across the top. What changes is whether the top row and left column are marked up as headers (th) or as plain data cells (td), and whether the left column has any text. Use the heading rotor to jump between cases. Under each heading, "Expect" says what the row header and column header scripts should speak when the cursor is in the "Q2" column of the "North" row (or the equivalent cell).
